# 🌊 SSMMK Agencies — Aquaculture Business Website

A modern and responsive aquaculture business website built for **Sri Sai Murali Mohana Krishna Agencies (SSMMK Agencies)**, a trusted shrimp feed and pond chemical supplier in Srikakulam, Andhra Pradesh.

This website helps farmers easily explore products, services, contact details, and place orders through WhatsApp.

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/ssmmk-agencies.git
```

---

## 2️⃣ Open Project Folder

```bash
cd ssmmk-agencies
```

---

## 3️⃣ Run Website

### Option 1 — Live Server (Recommended)

Install **Live Server** extension in VS Code.

Then:

* Right-click `index.html`
* Click **Open with Live Server**

---

### Option 2 — Direct Open

Simply open:

```bash
index.html
```

in your browser.

# 🚀 Deployment

This website is deployed using **GitHub Pages**.

## Deploy Steps

1. Push project to GitHub
2. Open repository settings
3. Go to **Pages**
4. Select:

   * Branch → `main`
   * Folder → `/root`
5. Save

GitHub will generate a live website link.
